# Changelog

Wszystkie istotne zmiany w projekcie **Domowe Archiwum** będą dokumentowane w tym pliku.

Changelog został rozpoczęty od wersji `1.2.1`.
Wcześniejsze wersje aplikacji nie posiadały prowadzonej historii zmian.

Format oparty o standard:
[Keep a Changelog](https://keepachangelog.com/pl/1.1.0/)

---

# [1.3.0](https://github.com/KlapkiSzatana/archive-app/releases/tag/v1.3.0) - 2026-05-15

## ✨ Added
- Dodanie wyświetlania rozmiaru poszczególnych katalogów
- Dodanie możliwości importowania całych katalogów wraz z zawartością

## 🔄 Changed
- Ulepszenie sposobu prezentacji danych w aplikacji
- Usprawnienia procesu dodawania oraz organizacji archiwów
- Poprawa wygody pracy z dużą ilością plików

## 🛠 Fixed
- Poprawki stabilności podczas pracy z większymi katalogami
- Poprawki obsługi wybranych operacji na plikach

## 🧹 Technical
- Porządki i optymalizacje kodu aplikacji
- Przygotowanie aplikacji pod dalszy rozwój funkcji archiwizacji

# [1.2.1](https://github.com/KlapkiSzatana/archive-app/releases/tag/v1.2.1) - 2026-05-07

## ✨ Added
- Dodano automatyczną kompilację kompletnej paczki aplikacji dla systemów Linux
- Dodano paczkę `ArchiveApp_linux.tar.gz`
- Dodano folder aplikacji wraz ze skrótem `.desktop`
- Dodano skrypty `install.run` oraz `uninstall.run`
- Dodano możliwość łatwiejszej instalacji aplikacji na dystrybucjach innych niż Arch Linux

## 🔄 Changed
- Usprawniono proces budowania oraz dystrybucji aplikacji
- Ulepszono integrację aplikacji ze środowiskiem Linux Desktop

## 🛠 Fixed
- Poprawiono stabilność procesu przygotowywania paczek aplikacji
- Naprawiono drobne problemy związane z instalacją środowiska aplikacji

## 🧹 Technical
- Wprowadzono porządki w systemie buildów projektu
- Przygotowano aplikację pod dalszy rozwój wersji desktopowej
